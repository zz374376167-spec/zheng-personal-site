# Project Context

## Project Name

Zheng Personal Website

## Owner

Name:
詹政

Identity:
学生

## Website Purpose

This website is a personal digital archive.

The purpose is to help people understand Zheng through:

- personal story
- life experiences
- photographs
- interests
- aesthetics

## Target Audience

People who want to know Zheng.

The website should create the feeling:

"I want to know this person."

## Brand Position

Zheng is:

A person who records life.

The website should communicate:

- authenticity
- curiosity
- personal taste
- calm confidence

## Main Content

Primary content:

- Personal photographs
- Life moments

Secondary content:

- Personal introduction
- Growth journey
- Education experience
- Interests
- Music taste
- Movie taste

## Website Language

Primary:

Chinese

Future possibility:

Support English version if needed.

## Design Direction

Style:

Minimal + Metallic

Keywords:

- Minimal
- Premium
- Industrial
- Calm
- Artistic

Visual feeling:

Like a personal archive,
a photography book,
or a digital exhibition space.

## Reference

https://www.noth.in/

## Avoid

Do not create:

- traditional resume website
- excessive animations
- flashy effects
- generic portfolio templates
- too many cards
